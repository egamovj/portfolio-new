# Professional Portfolio | Jo'rabek Egamov

A premium, high-performance portfolio website built with **React 19**, **Framer Motion**, and **Vite**. This project showcases advanced frontend engineering, mentorship impact, and a sophisticated design system.

---

🚀 **Live Demo:** [egamovj.netlify.app](https://egamovj.netlify.app/)

---

## ✨ Features

- 🌍 **Multi-language Support:** Seamless integration with `i18next` for English, Uzbek, and Russian.
- 📱 **PWA Ready:** Installable web app with offline capabilities using `vite-plugin-pwa`.
- 🎨 **Premium UI/UX:** Glassmorphism, smooth scroll animations, and dynamic micro-interactions powered by **Framer Motion**.
- 🛠️ **Developer Tools:** Integrated Code Gallery (Snippets) and Blog section.
- 📬 **Contact System:** Functional contact form integrated with `emailjs`.
- 📊 **SEO Optimized:** Structured data (JSON-LD), Meta Tags, and high Lighthouse performance scores.
- 🔒 **Admin Dashboard:** Private management area integrated with **Firebase**.

---

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** Vanilla CSS (Custom Hooks & Modern CSS Properties)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Backend/DB:** [Firebase](https://firebase.google.com/)
- **Internationalization:** [i18next](https://www.i18next.com/)
- **Deployment:** [Netlify](https://www.netlify.com/)
